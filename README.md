```bash
npm ci
npm run docs:dev
npm run docs:build
```

## GitHub Pages setup

Under **Settings → Pages → Build and deployment**, select **GitHub Actions**. The workflow in `.github/workflows/deploy.yml` builds and deploys the VitePress documentation on pushes to `main`. Check **Actions** for successful deployment before claiming the website is live.
